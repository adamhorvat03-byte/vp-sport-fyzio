# Pravidlá projektu VP Sport & Fyzio (Continuous Deployment)

## Automatický Git Commit & Push (CD Workflow)
- Každú jednu úpravu alebo novú funkciu, ktorú vypracuješ a používateľ ju schváli (alebo zadá na priame zapracovanie), **automaticky pridaj do Gitu (`git add -A`), vytvor výstižný commit (`git commit -m "..."`) a pushni priamo do vetvy `main` (`git push origin main`)**.
- Hlavná produkčná vetva je vždy `main`.
